# بوتیک — نسخه محلی Android

این مخزن بر اساس `implementation-spec-fa.md` شروع شده است. محدوده فعلی فقط یک اپ Flutter برای بوتیک است. تصمیم‌های تغییر دامنه و وضعیت واقعی هر بسته در [`docs/implementation-plan.md`](docs/implementation-plan.md) و [`IMPLEMENTATION_STATUS.md`](IMPLEMENTATION_STATUS.md) ثبت شده‌اند.

در این نسخه می‌توانید نام بوتیک را ثبت کنید، با کد ثابت `22222` وارد شوید و لباس و قیمت/موجودی را همراه عکس در فضای خصوصی اپ نگه دارید. نوار پایین فقط دو بخش دارد: «اپراتور» فهرست لباس و دکمه افزودن را نشان می‌دهد و لمس هر لباس جزئیاتش را باز می‌کند؛ «مشتری» مستقیماً دوربین جلو را باز می‌کند. ورودی کد و عدد، ارقام فارسی/عربی را هم می‌پذیرد. دیتابیس Drift/SQLite و عکس‌ها هر دو محلی هستند.

دکمه تحلیل هوش مصنوعی خطای واضح می‌دهد و هیچ API را فراخوانی نمی‌کند. در بخش مشتری، پس از تشخیص بدن روی ویدیو پیام کوتاه متحرک می‌آید و سپس عکس لباس، قیمت، و دکمه‌های لایک/دیسلایک نمایش داده می‌شوند. علامت شست بالا/پایین نیز در صورت آماده‌شدن مدل محلی همان رأی را ثبت می‌کند و لباس بعدی را می‌آورد. نمایشگر خارجی شناسایی‌شده خودکار متصل می‌شود. در فرم لباس عکس‌برداری با دوربین پشت هم وجود دارد. جای‌گذاری تصویر با MediaPipe تقریبی است؛ رفتار دوربین، علامت دست و پروژکتور روی گوشی آزموده نشده، و عکس JPEG با پس‌زمینه است و برش/شبیه‌سازی پارچه ندارد. اپ ادمین و سرور نداریم. داده‌ها با حذف نصب یا پاک‌کردن داده برنامه حذف می‌شوند؛ بک‌آپ و همگام‌سازی وجود ندارد.

برای اجرا از پوشه `apps/store_app`:

```powershell
flutter pub get
dart run build_runner build
flutter analyze --no-pub
flutter test --no-pub
flutter run -d <android-device-id>
```

ساخت APK: `flutter build apk --debug --no-pub`. روی این میزبان Android SDK 36 و NDK 28.2.13676358 موجود نیست؛ نتیجه دقیق تلاش ساخت در فایل وضعیت ثبت شده است. آزمون دستی دوربین/نمایشگر در [`docs/live-preview-device-check.md`](docs/live-preview-device-check.md) آمده است. هیچ APK انتشار با کلید ثابت تولید نشده است. فونت Vazirmatn و مجوز OFL آن در `apps/store_app/assets/fonts` قرار دارند.

برای ساخت ابری APK آزمایشی، workflow گیت‌هاب در `.github/workflows/android-debug.yml` با هر push به `main` اجرا می‌شود؛ می‌توانید آن را از زبانه `Actions` و گزینهٔ `Run workflow` هم دستی اجرا کنید. لینک عمومی دانلود همیشه این است: `https://github.com/mohamad72/bootic/releases/download/debug-latest/bootic-debug.apk`. با هر build موفق، فایل همین Release جایگزین می‌شود. Artifact همان اجرا هم در بخش `Artifacts` می‌ماند. APK با کلید debug ساخته می‌شود و برای انتشار فروشگاهی نیست.
