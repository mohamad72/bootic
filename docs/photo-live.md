# پرو زنده با عکس و سطح انعطاف‌پذیر

مبنای پچ: `5d25d1d`؛ روی نسخه پارامتری اعمال شود، بدون اعمال دوباره پچ‌های قبلی.

```bash
git apply --check bootic-photo-live.patch
git apply bootic-photo-live.patch
```

- عکس اصلی با مرزهای JSON نمایش داده می‌شود؛ سرویس حذف پس‌زمینه یا ساخت لباس از رنگ و استوانه اجرا نمی‌شود.
- پرامپت قابل کپی فرم اکنون عکس و هندسه `bootic.garment-metadata/0.1` را می‌خواهد. خروجی کامل، فرم را هم پر می‌کند.
- اطلاعات قدیمی هندسه عکس و مدل قدیمی دارای `source_metadata` معتبر قابل استفاده‌اند. مدل‌هایی که صرفاً پارامتری هستند، حذف نمی‌شوند؛ لازم است پاسخ پرامپت جدید را با همان عکس اصلی در فرم دوباره وارد کنید.
- اتصال آستین و تنه با میدان تغییرشکل مشترک روی یک شبکه انجام می‌شود. بالابردن دست زیر بغل را اندکی بالا می‌کشد؛ آستین بلند آرنج و مچ را دنبال می‌کند. پایین لباس پس از جابه‌جایی بدن کمی تأخیر دارد و در سکون می‌ایستد.
- محدوده یقه از چندضلعی عکس می‌آید؛ برش مستطیلی گردن و استوانه آستین حذف شده‌اند. برای اصلاح پشت یقه، مرز سوراخ در JSON باید واقعاً قسمت پشت/برچسب را جدا کند.
- دست جلوی تنه با تخمین محافظه‌کارانه عمق مفاصل پوشانندگی دارد؛ این روش نقشه عمق پیکسلی یا تشخیص دقیق انگشتان نیست.
- چروک و سایه عکس ورودی در بافت باقی می‌ماند. فعلاً عکس صاف با نور یکنواخت استفاده کنید؛ حذف خودکار چروک یا ساخت نمای پشت اضافه نشده است.
- قیمت و موجودی خالی `null` می‌مانند؛ صفر صریح همچنان صفر است. پایگاه داده، عکس‌ها و فعال‌سازی تغییر نمی‌کنند.

## محدوده و آزمون روی گوشی

هدف این مرحله تی‌شرت و لباس بالاتنه، روبرو و نیم‌رخ ملایم است؛ این رندر ادعای پرو دقیق اندازه یا شبیه‌سازی کامل سه‌بعدی/پشت لباس ندارد. تناسب شلوار و دامن در این پچ توسعه نیافته است.

با هر دو دوربین، در دو فاصله، دست پایین، دست بالا، دست جلوی سینه، آرنج خم و چرخش ملایم بررسی شود. دیباگ باید `photo-cloth-v1` و نوع دوربین را نشان دهد. کیفیت مرزها به عکس و JSON وابسته است. قبل از مقایسه، همان JSON هندسه عکس قبلی را نیز امتحان کنید.

اعتبارسنجی محیط توسعه: ۴۴ تست Kotlin، کامپایل رندر با API اندروید، ۴۹ بررسی ورود فرم، ۴۱ بررسی مدل/مقادیر خالی و بررسی هندسه نمونه. ابزار Flutter در محیط موجود نبود؛ بیلد کامل APK، تست ویجت و تست دوربین روی دستگاه انجام نشده است.
