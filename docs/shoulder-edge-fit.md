# اصلاح اتصال شانه و دیباگ لبه — pose-v5-edges

این پچ **افزایشی** است و بعد از پچ JSON نصب می‌شود؛ شامل اصلاحات دوربین یا فرم لباسِ قبلی نیست.

```sh
git apply --check ./bootic-shoulder-edge-fit.patch
git apply ./bootic-shoulder-edge-fit.patch
```

فقط اگر دستور اول موفق بود دستور دوم را اجرا کنید. روی نسخهٔ دقیق حاصل از
`bootic-garment-json-after-camera.patch` (و پچ تجمعی JSON قبلی) ساخته شده است.

## رفتار

- نقاط خام مفاصل MediaPipe و پذیرش بدن تغییر نمی‌کنند. نقاط بالای لباس JSON از مرز نزدیک شانه استفاده می‌کنند؛ لگن در همان محل می‌ماند.
- ماسک بدن از همان PoseLandmarker و همان فریمِ چرخیده/آینه‌شده گرفته می‌شود. مدل، سرویس یا تماس شبکهٔ جدیدی اضافه نشده است. این ماسکِ بدن مشتری است و ارتباطی به سرویس حذف پس‌زمینهٔ عکس لباس ندارد.
- در هر شانه پنج مسیر در جهت بالای تنه بررسی می‌شود. حداقل سه مسیر باید مرز روشن پیش‌زمینه/پس‌زمینه و نتیجهٔ سازگار بدهند. شانهٔ کم‌اطمینان، مرز بیرون کادر، بدن خیلی کوچک یا ماسک نامعتبر باعث بازگشت به اتصال قبلی می‌شود.
- محدودهٔ جست‌وجو حداکثر ۲۰٪ طول تنه است؛ این سقف محافظتی است، نه جابه‌جایی ثابت. مقدار واقعی از ماسک می‌آید. هیچ عدد سانتی‌متری، تصویر یا اندازهٔ شخصی برای تنظیم مدل استفاده نشده و هیچ آموزشی انجام نشده است.
- رندر JSON روی گوشی و نمایشگر خارجی از نقاط اصلاح‌شده استفاده می‌کند. مسیر قدیمیِ بدون JSON تغییری در فیت ندارد.
- رفتار لایک، پایان نمایش لباس‌ها و زمان‌بندی افکت‌ها تغییری ندارد.

## دیباگ و تست گوشی

عنوان همیشه دوربین جلو/عقب را نشان می‌دهد. رنگ سبز مفاصل خام، صورتی نمونه‌های مرز ماسک بدن، زرد محل اتصال اصلاح‌شدهٔ شانه است. خط زرد فاصلهٔ مفصل تا اتصال را نشان می‌دهد. صورتی تخمین سطح بدن و لباس پوشیده‌شده است، نه پوست پنهان زیر لباس و نه بازسازی سه‌بعدی.

اعداد «اصلاح شانه ۱۱/۱۲» فاصله در پیکسلِ تصویر مدل هستند، نه سانتی‌متر و نه پیکسل اسکرین‌شات. «لبه: هر دو شانه/یک شانه» یعنی اصلاح فعال شده؛ «مرز مطمئن نیست» یعنی اتصال قبلی حفظ شده است. جزئیات بازشونده اندازهٔ ماسک و زمان استخراج لبه را هم دارند. FPS و تأخیر کل برای بررسی هزینهٔ خروجی ماسک مهم‌اند؛ روی گوشی هنوز اندازه‌گیری نشده است.

برای ارزیابی، از جلو و عقب، نزدیک و دور، ابتدا بدون لباس مجازی مثل عکس‌های فعلی و سپس با لباس مجازیِ نیمه‌شفاف عکس بگیرید. گردن و شانه در عکس پوشیده از پنل نباشد؛ جزئیات را در صورت لزوم جمع کنید. زاویهٔ سه‌رخ و یک نفر دیگر برای سنجش تعمیم مفید است. عدد FPS، حالت دوربین، وضعیت لبه و اصلاح شانه را در عکس نگه دارید.

ماسک فقط داخل callback مصرف می‌شود. نقاط مرز با سقف ۱۲۰۰ نمونه فقط در حالت دیباگ تولید و ارسال می‌شوند؛ فریم/ماسک کامل ذخیره یا به Flutter ارسال نمی‌شود. فعال کردن خروجی ماسک ممکن است هزینهٔ پردازشی اضافه کند؛ این نسخه تضمین افزایش سرعت یا حذف کامل خطای فیت نیست.

## اعتبارسنجی این پچ

تست‌های JVM شامل اصلاح مرز، نبود مرز، پوشیدگی، چرخش، آینه، فاصله، اندازه‌های مختلف تنه، اتصال آستین و ثابت ماندن لگن است. کامپایل کلاس‌های رندر و PoseTracker با API واقعی MediaPipe 1.0.0 انجام شده است. بیلد کامل Flutter/APK و تست روی گوشی در محیط حاضر انجام نشده است.
