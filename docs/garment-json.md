# ورود دستی اطلاعات JSON برای پرو زنده

این نسخه پس از اعمال پچ `bootic-camera-crop-fix.patch` روی کامیت `7842ef3` اعمال می‌شود؛ تغییرات دوربین قبلی را دوباره اضافه نمی‌کند. ساخت JSON با هوش مصنوعی یا فراخوانی API اضافه نشده است.

## استفاده

۱. در فرم افزودن یا ویرایش لباس، بخش «اطلاعات پرو زنده» را باز کنید و JSON کامل با نسخهٔ `bootic.garment-metadata/0.1` را در فیلد «مشخصات لباس (JSON)» بچسبانید.
۲. عکس اصلی روبرو، یعنی همان عکس مبنای JSON را انتخاب کنید. با وجود JSON، ماسک چندضلعی برای آماده‌سازی عکس به‌کار می‌رود و به مدل حذف پس‌زمینه نیاز نیست. برنامه یک نسخهٔ کامل و بدون برش از بوم عکس را هم نگه می‌دارد. برای لباس‌های قدیمی که این نسخه را ندارند، انتخاب دوبارهٔ عکس اصلی لازم است.
۳. لباس را ذخیره کنید. متن کامل JSON همراه خود لباس ذخیره می‌شود، در ویرایش دوباره بازمی‌گردد و مشخصات فعلی لباس پاک نمی‌شوند. قسمت‌های نامعتبر با پیام فارسی مشخص می‌شوند؛ ذخیرهٔ آن‌ها انجام نمی‌شود.
۴. در دوربین مشتری، نسخهٔ دیباگ `pose-v4-json` و ردیف رندر `metadata-mesh-v1` نشان می‌دهند که مسیر جدید فعال است. لباس بدون JSON همچنان از مسیر قبلی نمایش داده می‌شود. با پاک‌کردن فیلد JSON نیز می‌توان به مسیر قبلی برگشت.

## بخش‌های مصرف‌شده در رندر

- ابعاد بوم در `source.width_px/height_px` و نقاط بر حسب پیکسل عکس اصلی؛ تغییر اندازهٔ متناسب عکس واردشده در محاسبات لحاظ می‌شود. عکس با نسبت ابعاد متفاوت رد می‌شود.
- محدودهٔ بیرونی `segmentation.outer_contour_px` و حفره‌های `subtract_polygons_px`، از جمله حذف پشت یقه و برچسب داخل دهانهٔ گردن. ماسک با لبهٔ آنتی‌الیاس ساخته می‌شود و خود عکس اصلی دست‌نخورده باقی می‌ماند.
- نقاط `shoulder_image_left/right` و `hem_center` در `landmarks_px` برای اتصال عکس به شانه‌ها و مرکز لگن؛ جایگذاری بر اساس این نقاط است، نه کشیدن کل مستطیل عکس روی بدن.
- چندضلعی آستین‌های چپ و راست در `regions`، نقاط زیر بغل و مرکز لبهٔ آستین برای مش جداگانهٔ آستین. آرنج نامطمئن باعث برگشت آستین به نگاشت تنه می‌شود. درز شانه تا زیر بغل به تنه متصل می‌ماند.
- گزینهٔ `mirror_texture_only_if_front_camera_is_mirrored` برای بافت عکس. نقاط بدن، تبدیل و آینه‌شدن دوربین را قبلاً طی کرده‌اند و دوباره آینه نمی‌شوند.
- رندر مش روی گوشی و نمایشگر دوم مشترک است؛ ماسک و بافت فقط هنگام تعویض لباس آماده می‌شوند. لودینگ دوثانیه‌ای و حالت نیمه‌شفاف دیباگ حفظ شده‌اند.

این مرحله یک رندر دوبعدی با تغییر شکل تنه و آستین است. متن‌های پیشنهادی مربوط به فیزیک پارچه، بازسازی سطح پشت، عمق سه‌بعدی و ماسک دست و پوست جلوی لباس ذخیره می‌شوند، اما هنوز اجرا نشده‌اند. رشته‌های دستور داخل JSON هیچ کد یا پرامپتی را اجرا نمی‌کنند.

## بررسی

فایل نمونهٔ کاربر در `apps/store_app/test/fixtures/striped_tshirt_metadata.json` قرار دارد. بررسی مستقل Dart:

`cd apps/store_app && dart tool/check_render_metadata.dart`

آزمون‌های هندسهٔ اندروید:

`cd apps/store_app/android && ./gradlew :app:testDebugUnitTest`

بررسی روی گوشی: همان JSON و عکس مبنا را ذخیره کنید؛ فرم را ببندید و دوباره باز کنید؛ سپس نزدیک و دور، چرخش بدن، بالا آوردن دست، تعویض دوربین و تغییر لباس را تست کنید. دهانهٔ گردن باید شفاف باشد و اتصال شانه و پایین لباس همراه بدن بماند. بیلد کامل Flutter و تست دوربین واقعی در این محیط تأیید نشده‌اند.
