# آزمایشگاه وب پرو

کاربر یک شاخهٔ مستقل و اجرای محلی وب می‌خواهد. تأیید اضافی لازم نیست (دستور صریح کاربر).

دو تب بزرگ: مرز لباس ورودی و قرارگیری روی عکس ثابت. تشخیص زندهٔ بدن به گوشی موکول می‌شود. ورودی عکس لباس با حذف زمینهٔ یکدست آزمایشی و امکان ورود JSON نسخهٔ metadata/0.1 برنامه. عکس نمونهٔ آدم با اتصال‌های دستی و قابل‌اصلاح ارائه شود؛ این نقاط خروجی مدل تشخیص بدن نیستند. لباس نمونه برای تست فوری هم قرار بگیرد.

روش: ابزار HTML/Canvas مستقل و بدون وابستگی در apps/web_tryon تا محدودیت dart:io و پایگاه دادهٔ برنامه مانع تست وب نشوند. هیچ دوربین یا سرویسی استفاده نمی‌شود و عکس‌های آپلودی محلی می‌مانند. شبکهٔ مثلثی وب با ورودی هندسی سازگار و نگاشت شانه/لگن/بازو؛ شفافیت و مرز و شبکه قابل تغییر. این مسیر آزمایشی وب، معادل تضمین‌شدهٔ رندر Kotlin نیست. روش جایگزین تبدیل کل Flutter app نیازمند تغییر ذخیره‌سازی و پورت رندر اندروید است و فعلاً خارج از هدف تست سریع است.

خطاهای قابل بررسی: برش اشتباه، حفرهٔ یقه، اتصال شانه و کشیدگی نقش لباس. کیفیت دادهٔ عکس نمونه با مشاهده و نقاط قابل اصلاح بررسی شود؛ مرز «قطعی» یا ground truth ادعا نشود. الگوریتم ساده زمینه برای عکس لباس پوشیده‌شده یا زمینه پیچیده مناسب نیست.

تست: استخراج زمینه، حفظ حفره، اعتبارسنجی JSON و مختصات، نگاشت اتصال و مثلث‌ها، تعامل مرورگر روی آپلود و تب‌ها، و اجرای سرور لوکال. شاخه main تغییر نکند.
